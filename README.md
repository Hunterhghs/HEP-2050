# HEP-2050 — Human Exposure to the Polycrisis in 2050

A single-page digital report by H Heuristics mapping how many people will face air
pollution, water scarcity, extreme heat, income insecurity, and conflict in 2050 —
and where those stressors overlap.

- **Format:** one self-contained `index.html` (Chart.js + Google Fonts via CDN)
- **Built with:** Veles (Fable-5 × DeepSeek), verified by the Veles Verifier gate
- **Deploy:** GitHub Pages → Settings → Pages → Deploy from branch `main`, root folder

## Content

1. The polycrisis frame — five stressors, one exposure
2. Five exposure fronts in 2050 (air, water, heat, poverty/no income, conflict)
3. Compound exposure — the overlap is the story
4. Hotspots — where 2050 exposure concentrates
5. Scenarios — exposure is a policy outcome
6. Methodology & sources

All figures are scenario estimates and syntheses from cited sources (WHO, IPCC AR6,
World Bank Groundswell, UN-Water, C40, ILO, UNHCR, OECD, IEA, UNICEF), not predictions.
